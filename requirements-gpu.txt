# Versions pinned to a known-compatible set for torch 2.11 + CUDA 12.8 (Colab, mid-2026).
#
# IMPORTANT — avoid the torch-reinstall trap:
#   The default `pip install vllm` wheel is built for CUDA 12.9 and bundles its own
#   torch (2.11.0+cu129), which OVERWRITES Colab's preinstalled torch 2.11.0+cu128.
#   To keep the cu128 build, install with the cu128 torch index:
#
#     pip install -r requirements-gpu.txt --extra-index-url https://download.pytorch.org/whl/cu128
#
#   Then verify torch is untouched:  python -c "import torch; print(torch.__version__)"
#   (should print 2.11.0+cu128). DeepSpeed compiles CUDA ops against the installed
#   torch at install time, so make sure torch is final BEFORE this installs.
